# Acknowledgments

The node operator guides in this section were written in 2026 under a documentation program funded by the XRP Ledger Foundation. They are built on evidence rather than opinion: a survey of operators running every role on the network, written questionnaires and interviews with operators of production fleets, sanitized configuration files, measured figures from live servers, and two rounds of review in which operators checked every page against their own experience and the server's source code. Where the guides state a number, an operator measured it; where they recommend a practice, operators run it.

The people and organizations below contributed survey answers, interviews, questionnaire answers, artifacts, or reviews. Several contributed in more than one way. Three further operators contributed anonymously.

## How to contribute

These guides describe practice as operators run it today. If your experience differs, or the server has changed, open a pull request or an issue against the [xrpl-dev-portal repository](https://github.com/XRPLF/xrpl-dev-portal), as with any other page on this site.
