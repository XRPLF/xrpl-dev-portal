# 代替可能トークン

代替可能トークンは何らかの価値を表すもので、その多くはブロックチェーンの外に存在する資産を表現したものです。[NFT](../nfts/index.md)とは異なり、代替可能トークンはすべての単位が同じトークンの他の単位と交換できます。刷りたての紙幣であっても、スマートフォンの決済アプリに並ぶ数字であっても、1米ドルの価値は1米ドルであるのと同じです。

XRP Ledgerには代替可能トークンの規格が2つあり、これはトークンが実際にどう使用されてきたかを踏まえた進化の産物です。

- **トラストライントークン** は代替可能トークン規格の「バージョン1」です。XRP Ledgerの本番環境で完全に利用できますが、使用する前に知っておくべきいくつかの重要なエッジケースがあります。
- **Multi-Purpose Token(MPT)** は代替可能トークン規格の「バージョン2」です。現在も開発が進んでおり、トラストライントークンと完全に同じ機能が揃っているわけではありません。XRP Ledgerのトラストライントークンから得られた知見をもとに、効率と使いやすさを高める目的で設計されました。 {% amendment-disclaimer name="MPTokensV1" /%}

どちらのトークンも、[フリーズ](freezes.md)、[回収](clawing-back-tokens.md)、[許可リスト](authorized-trust-lines.md)といったコンプライアンス向けの機能に対応しています。2つの規格はそれぞれ違う強みを持つため、当面はどちらも引き続きサポートされる見込みです。

## トラストライントークン

トラストライントークンは、ユーザ間で相互にトークンを発行できる双方向の信頼モデルを採用した代替可能トークンです。管理を担うのは _トラストライン_ と呼ばれるオンチェーンのデータ構造で、これは単一の通貨コードについて2つのアカウント間に結ばれる双方向の関係を指します。

トラストライントークンはXRP Ledgerのローンチ当初から存在し、その後のプロトコルの改訂に伴い成長を遂げてきました。[異なる通貨間の支払い](../../payment-types/cross-currency-payments.md)に利用でき、[分散型取引所](../decentralized-exchange/index.md)での取引にも対応します。

同一の通貨コードを持ち、発行者が異なるトークンの間では、[Rippling](rippling.md)機能を使用できます。これは、多数の当事者が関与する支払いをアトミックに決済し、相殺できる重要な機能です。この特性により、コミュニティクレジットのユースケースではトラストライントークンが標準として選ばれます。ただし、設定が適切でない場合、同一の通貨コードを用いる別々の発行者のトークン間で、意図しない、あるいは望ましくない移動が生じることがあります。

多くのプロパティはアカウント単位で定義されます。したがって、同一のアカウントが発行するトークンはすべて同じプロパティを共有します。また、残高には浮動小数点表現を用いるため、非常に大きな量から非常に小さな量までを扱える一方で、予期しない丸めの影響が生じることがあります。

特性や使用方法の詳細は[トラストライントークン](trust-line-tokens.md)を参照してください。

## Multi-Purpose Token

Multi-Purpose Token(MPT)は、一方向モデルを採用した代替可能トークンです。このモデルでは、発行者がまず各種のプロパティを持つ _MPT発行_ を定義し、そのうえでトークンの単位を保有者へ発行します。トラストライントークンとの主な相違点は以下のとおりです。

- **よりシンプルな概念モデル:** 発行が一方向で、Ripplingがなく、精度が固定小数点であるため、MPTを発行または利用する統合を実装する際に考慮すべきエッジケースが減ります。
- **トークンごとに独立したプロパティ:** オンチェーンのMPT発行定義がそのトークンのプロパティを保持するため、同一の発行者による他のトークンとは異なる設定を適用できます。
- **効率的な保存形式:** MPTは、共有レジャー上での保存と送信に要する領域が小さくなるよう設計されています。そのぶんネットワークは、大量のトランザクションをより効率的に処理できます。

MPTの特性や使用方法の詳細は[Multi-Purpose Token](multi-purpose-tokens.md)を参照してください。

### MPT機能の実装状況

MPT関連の機能は、トラストライントークンとほぼ同等の水準に近づけるため、XRP Ledgerプロトコルへの一連のAmendmentによって追加が進んでいます。ただし、Ripplingなど一部の機能は、概念モデルを簡潔に保つために意図的に実装されません。

主な機能とその状況は以下のとおりです。

| MPTの機能 | Amendment / 規格 |
|-------------|----------------------|
| 発行と直接の支払い | {% amendment-disclaimer name="MPTokensV1" compact=true /%} |
| エスクロー | {% amendment-disclaimer name="TokenEscrow" compact=true /%} （トラストライントークンとMPTの双方にエスクローを実装） |
| 変更可能なトークンプロパティ | 開発中: [XLS-94](https://github.com/XRPLF/XRPL-Standards/tree/master/XLS-0094-dynamic-MPT) |
| 機密性 | [提案中のXLS](https://github.com/XRPLF/XRPL-Standards/discussions/372) |
| 分散型取引所(DEX)、取引、異なる通貨間の支払い、AMMとの互換性 | [提案中のXLS](https://github.com/XRPLF/XRPL-Standards/discussions/231) |

## どちらの代替可能トークンを使用するか

XRP Ledgerで新たにトークンを作成する際は、特性も強みも異なる2つの規格から選択することになるため、判断に迷う場合があります。いずれを使用すべきか決めかねる場合は、以下の要約を判断の材料としてください。

- 新規のトークンには、多くの場合MPTが適しています。
- トラストライントークンのほうが適している具体的なケースは以下のとおりです。
    - **DEXとの互換性** が必要な場合
    - ユースケースが **コミュニティクレジット** である場合
    - すでにトラストライントークンで動作している統合など、レガシーなソフトウェアとの互換性が必要な場合
    - 同一のトークンで、20桁ほど離れた大きな量と小さな量を扱う必要がある場合

これは、各規格の長所と短所を網羅した一覧ではありません。判断に迷う場合は、[トラストライントークン](trust-line-tokens.md)と[MPT](multi-purpose-tokens.md)それぞれのプロパティを詳しく確認したうえで決定してください。
