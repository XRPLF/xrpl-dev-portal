# トークンのフリーズ

発行者は、自身が発行したトークンをXRP Ledgerでフリーズできます。**これはXRPには適用されません。** XRPはXRP Ledgerのネイティブアセットであり、発行されたトークンではないためです。

規制要件を満たすため、あるいは疑わしい活動を調査している間など、特定のケースでは、発行者が自身の発行した残高をフリーズしたい場合があります。このページでは、[トラストライントークン](./trust-line-tokens.md)のフリーズ機能について説明します。

{% admonition type="success" name="ヒント" %}XRP LedgerのXRPは、誰もフリーズできません。ただし、カストディアル取引所は、自らの裁量でいつでも保管資金をフリーズできます。詳細は、[フリーズに関するよくある誤解](common-misconceptions-about-freezes.md)を参照してください。{% /admonition %}

トラストライントークンには、フリーズに関する次の設定があります。

* [**Individual Freeze（個別のフリーズ）**](#individual-freeze) - 1つの取引相手をフリーズし、その取引相手がトークンを使えないようにします。
* [**Deep Freeze（ディープフリーズ）**](#ディープフリーズ) - 1つの取引相手をさらにフリーズし、その取引相手がトークンを受け取ることもできないようにします。
* [**Global Freeze（全体のフリーズ）**](#global-freeze) - すべての取引相手をフリーズします。
* [**No Freeze（フリーズ機能の放棄）**](#no-freeze) - 個々の取引相手をフリーズする機能と、Global Freezeを解除する機能を永久に放棄します。

フリーズ対象の残高がプラスかマイナスかにかかわらず、すべてのフリーズ設定を行うことができます。トラストラインは、トークンの発行者と通貨の保有者のどちらでもフリーズできますが、通貨の保有者がフリーズしても、その影響はわずかです。

[MPT](./multi-purpose-tokens.md)にも同様の機能がありますが、「ロック」と呼ばれます。また、MPTの個別のロックは、常にディープフリーズと同様に機能します。


## Individual Freeze

**Individual Freeze**機能は、[トラストライン](index.md)に関する設定です。発行者がIndividual Freeze設定を有効にすると、そのトラストラインのトークンに次のルールが適用されます。

* フリーズされたトラストラインの両当事者間の直接の支払いは、引き続き行うことができます。
* そのトラストラインの取引相手は、発行者への直接の支払いを除き、フリーズされたトラストラインの残高を減らすことができなくなります。取引相手は、フリーズされた通貨を発行者に直接送ることしかできません。
* 取引相手は、フリーズされたトラストラインで、他者からの支払いを引き続き受け取ることができます。
* フリーズされたトラストラインのトークンを売る取引相手のオファーは、[資金不足とみなされます](../decentralized-exchange/offers.md#オファーのライフサイクル)。

再確認: トラストラインはXRPを保持しません。XRPはフリーズできません。

金融機関は、疑わしい活動を行う取引相手や、金融機関の利用規約に違反する取引相手とのトラストラインをフリーズできます。金融機関は、XRP Ledgerに接続されている自身のその他のシステムでも、その取引相手をフリーズする必要があります。（そうしないと、そのアドレスは、金融機関を経由して支払いを送ることで、望ましくない活動を続けられる可能性があります。）

個々のアドレスは、金融機関とのトラストラインをフリーズできます。これは、その金融機関と他のユーザとの間の取引には影響しません。ただし、他のアドレス（[運用アドレス](../../accounts/account-types.md)を含む）が、その金融機関のトークンをその個々のアドレスに送ることはできなくなります。このようなIndividual Freezeは、オファーには影響しません。

Individual Freezeは1つのトラストラインに適用されます。特定の取引相手との複数のトークンをフリーズするには、通貨コードごとのトラストラインで、それぞれIndividual Freezeを有効にする必要があります。

[No Freeze](#no-freeze)設定を有効にしているアドレスは、Individual Freeze設定を有効にできません。


## ディープフリーズ

**ディープフリーズ**機能は、Individual Freezeをより厳しくしたトラストラインの設定です。発行者がディープフリーズを有効にすると、そのトラストラインのトークンに次のルールが適用されます。

- ディープフリーズされたトラストラインの両当事者間の直接の支払いは、引き続き行うことができます。
- 取引相手は、発行者への直接の支払いを除き、ディープフリーズされたトラストラインの残高を増やすことも減らすこともできなくなります。
- 取引相手は、ディープフリーズされたトラストラインで、他者との間で送受信ができなくなります。
- ディープフリーズされたトークンを売買する取引相手の[オファー](../decentralized-exchange/offers.md)は、資金不足とみなされます。取引相手は、そのトークンを売買する新しいオファーを出すことができません。
- ディープフリーズされたトラストラインを[Ripplingで経由する](./rippling.md)支払いは許可されません。支払いは、可能であれば別のパスを使う必要があり、そうでなければ失敗します。

個々のアドレスが、発行者へのトラストラインをディープフリーズすることもできます。これは、その発行者と他の保有者との間の取引には影響しません。ただし、次の効果があります。

- 他者が、ディープフリーズされたトークンをその個々のアドレスに送ることを防ぎます。
- その個々のアドレスが、発行者以外のアドレスにそのトークンを送ることも防ぎます。
- その個々のアドレスが、ディープフリーズされたトークンを売買するオファーを出すことを防ぎます。
- ディープフリーズされたトラストラインを経由するRipplingによる支払いを止めます。

ディープフリーズは、Individual Freezeよりも _一段上_ のフリーズです。トラストラインにディープフリーズを設定できるのは、Individual Freezeがすでに設定されているか、同時に設定する場合のみです。通常のIndividual Freezeは、ディープフリーズも同時に解除しない限り解除できません。一方、ディープフリーズは、Individual Freezeを維持したまま解除 _できます_ 。

[No Freeze](#no-freeze)設定を有効にしているアドレスは、ディープフリーズ設定を有効にできません。

## Global Freeze

**Global Freeze**機能は、アカウントに関する設定です。アカウントは、自身に対してのみGlobal Freezeを有効にできます。発行者がGlobal Freeze機能を有効にすると、その発行者が発行するすべてのトークンに次のルールが適用されます。

* フリーズされた発行者のすべての取引相手は、発行者への直接の支払いを除き、フリーズされたアカウントへのトラストラインの残高を減らすことができなくなります。（これは、発行者自身の[運用アドレス](../../accounts/account-types.md)にも影響します。）
* フリーズされた発行者の取引相手は、発行アドレスとの間で直接の支払いを引き続き送受信できます。
* フリーズされたアドレスが発行したトークンを売るオファーはすべて、[資金不足とみなされます](../decentralized-exchange/offers.md#オファーのライフサイクル)。

再確認: アドレスはXRPを発行できません。Global FreezeはXRPには適用されません。

発行者の[秘密鍵](../../accounts/cryptographic-keys.md)が漏えいした場合には、そのアドレスの制御を取り戻した後であっても、金融機関の[発行アカウント](../../accounts/account-types.md)でGlobal Freezeを有効にすると役立ちます。これにより資金の流れが止まり、攻撃者がそれ以上の資金を持ち去ることを防ぐか、少なくとも何が起きたのかを追跡しやすくなります。XRP LedgerでGlobal Freezeを行うほかに、発行者は外部システムでの活動も停止する必要があります。

金融機関が新しい[発行アドレス](../../accounts/account-types.md)に移行する予定の場合や、事業を停止する予定の場合にも、Global Freezeを有効にすると役立ちます。これにより、特定の時点で資金がロックされるため、ユーザはその資金を他の通貨に交換できなくなります。

Global Freezeは、そのアドレスが発行および保有する _すべての_ トークンに適用されます。1つの通貨コードのみに対してGlobal Freezeを有効にすることはできません。一部のトークンだけをフリーズできるようにしたい場合は、トークンごとに異なるアドレスを使用してください。

アドレスは、いつでもGlobal Freeze設定を有効にできます。ただし、アドレスが[No Freeze](#no-freeze)設定を有効にしている場合、Global Freezeを _無効にする_ ことはできなくなります。


## No Freeze

**No Freeze**機能は、トークンを任意にフリーズする機能を永久に放棄するアドレスの設定です。発行者はこの機能を使うと、取引相手同士のトークンの取引に発行者が介入できないという意味で、自身のトークンを「より物理的なお金に近いもの」にできます。

再確認: XRPはもともとフリーズできません。No Freeze機能は、XRP Ledgerで発行されたその他のトークンにのみ適用されます。

No Freeze設定には次の効果があります。

* 発行者は、すべての取引相手とのトラストラインで、Individual Freezeやディープフリーズを有効にできなくなります。
* 発行者は、引き続きGlobal Freezeを実行できますが、Global Freezeを _無効にする_ ことはできなくなります。
* 発行者は、自身のトラストライントークンで[Clawback](./clawing-back-tokens.md)を有効にできなくなります。（MPTのClawbackには影響しません。）

XRP Ledgerは、発行者に対して、その発行した資金が表す債務を履行させることはできません。そのため、No Freezeを有効にしても、ステーブルコインの発行者が債務不履行に陥ることを防げるわけではありません。ただし、No Freezeにより、発行者が特定のユーザに対してGlobal Freeze機能を不当に使用しないことが保証されます。

No Freeze設定は、アドレスに対して発行されるトラストライントークンと、アドレスから発行されるトラストライントークンのすべてに適用されます。一部のトークンだけをフリーズできるようにしたい場合は、トークンごとに異なるアドレスを使用するか、[MPT](./multi-purpose-tokens.md)を使用してください。

No Freeze設定は、アドレスのマスターキーのシークレットで署名したトランザクションでのみ有効にできます。[レギュラーキー](../../../references/protocol/transactions/types/setregularkey.md)や[マルチシグトランザクション](../../accounts/multi-signing.md)を使用してNo Freezeを有効にすることはできません。

## Clawbackとの関係

[Clawback](./clawing-back-tokens.md)は、トークンの発行者が金融規制を遵守できるようにするためのもう1つの機能です。Clawbackを使うと、取引相手が保有する発行済みトークンを取り戻すことができますが、事前にClawback機能を有効にしている場合に限ります。

ClawbackとNo Freezeの設定は互いに排他的です。アドレスがNo Freeze設定を有効にしている場合、トラストライントークンのClawbackは有効にできません。また、アドレスのトラストライントークンでClawbackが有効になっている場合、No Freeze設定は有効にできません。

[Clawbackトランザクション][]は、発行者と保有者の間で直接機能するため、資金がフリーズされている場合でも資金を回収できます。

[AMMClawbackトランザクション][]も、フリーズ設定に関係なく、[AMM](../decentralized-exchange/automated-market-makers.md)に預け入れられたトークンを回収できます。`fixCleanup3_4_0` amendmentがない場合、発行者がAMMのトラストラインをフリーズしていると、AMMClawbackは資金を回収できません。{% amendment-disclaimer name="fixCleanup3_4_0" mode="updated" /%}

## MPTのロックとトラストライントークンのフリーズの比較

[MPT](./multi-purpose-tokens.md)を「ロック」する機能は、トラストライントークンを「ディープフリーズ」する機能とほぼ同じです。詳細は次の表を参照してください。

| 機能 | トラストライントークン | Multi-Purpose Token（MPT） |
|------|----------------------|---------------------------|
| 個別のフリーズ／ロック | 2つのフラグ: 通常の**Individual Freeze**（送金をブロック）と**Deep Freeze**（送金と受け取りをブロック） | 1つの**Lock**フラグ（送金 _と_ 受け取りをブロック） |
| 全体のフリーズ／ロック | 発行アカウントごと（**Global Freeze**設定） | トークンの発行ごと（**MPT Lock**設定） |
| フリーズ／ロック機能の放棄 | 発行アカウントごと（**No Freeze**設定） | トークンの発行ごと（**Can Lock**設定） |
| ClawbackとFreezeの関係 | **Clawback**と**No Freeze**の両方を有効にすることはできない | **Can Lock**と**Can Clawback**は任意の組み合わせで有効にできる |
