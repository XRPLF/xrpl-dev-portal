# アカウントのブラックホール化

アカウントのブラックホール化とは、アカウントの署名権限を恒久的かつ検証可能な形で取り除くことです。一度ブラックホール化されると、誰もそのアカウントからトランザクションを送信できなくなります。

## ブラックホール化する理由

アカウントのブラックホール化は極端な手段であり、ほとんどのアカウント所有者にとって検討の必要はありません。ユースケースには次のようなものがあります。
- **トークンの供給量が固定されていることの証明。** 発行アカウントをブラックホール化することで、所有者はユーザーやトークン保有者に対し、そのアカウントがこれ以上トークンを追加発行したり、送金手数料を変更したり、残高をフリーズしたりできないことを証明できます。
- **削除できないアカウントの廃止。** アカウントに[削除ブロッカー](deleting-accounts.md#削除ブロッカー)がある場合、そのアカウントは削除できません。ブラックホール化すればアカウントの署名権限が恒久的に取り除かれ、それ以降の操作を防げます。削除とは異なり、アカウントはレジャー上に残り、その準備金はロックされたままになります。

## 要件

ブラックホール化されたとみなされるには、アカウントが次の条件をすべて満たしている必要があります。
- マスターキーが無効化されている。
- レギュラーキーが既知の[ブラックホールアドレス](addresses.md#特別なアドレス)に設定されている。
- アカウントに[署名者リスト](multi-signing.md)がない。
- アカウントに[被委任者](permission-delegation.md)がいない。 {% amendment-disclaimer name="PermissionDelegationV1_1" /%}

## ブラックホール化の確認方法

ブラックホール化を暗号学的に証明する手段はありません。アカウントが上記の条件を満たしていることを検証できるだけです。

確認するには、[account_infoメソッド][]を呼び出し、次の点をすべて満たしていることを確かめます。
1. `lsfDisableMaster`フラグが設定されている。
2. `RegularKey`フィールドが既知の[ブラックホールアドレス](addresses.md#特別なアドレス)(ACCOUNT_ZEROの`rrrrrrrrrrrrrrrrrrrrrhoLvTp`、またはACCOUNT_ONEの`rrrrrrrrrrrrrrrrrrrrBZbvji`のいずれか)に設定されている。
3. [account_objectsメソッド][]を呼び出して、そのアカウントに[SignerListエントリ][]が存在しないことを確認する。
4. 同様に、そのアカウントに[Delegateレジャーエントリ](../../references/protocol/ledger-data/ledger-entry-types/delegate.md)が存在しないことを確認する。

ACCOUNT_ZEROとACCOUNT_ONEは、秘密鍵ではなく整数の0と1から導出されたアドレスであるため、既知のブラックホールアドレスとみなされます。このため、対応する秘密鍵を誰かが生成することは事実上不可能です。

レギュラーキーが既知のブラックホールアドレスではなく任意のアドレスに設定されている場合、対応する秘密鍵を誰も保持していないことを検証する方法はありません。

{% admonition type="info" name="注記" %}
ブラックホール化されたアカウントのトランザクション履歴には、他のアカウントがそのトークンを使用したり、そのアカウントに関係するトランザクションを完了したりした記録が引き続き表示されます。ブラックホール化されたアカウント自身がこれらのトランザクションを送信しているわけではありません。
{% /admonition %}

## リスクと制限事項

ブラックホール化は取り消せません。アカウントをブラックホール化する前に、次の点に注意してください。
- アカウントが保有するXRPはすべて恒久的に失われ、取り戻すことはできません。
- ブラックホール化後は、アカウントはいかなるトランザクションも送信できません。誤った設定(送金手数料、フリーズ権限、Ripplingなど)があっても、恒久的にそのまま固定されます。
- ブラックホール化前に作成された既存のレジャーエントリ(未決済のオファー、Escrow、Payment Channel、Checkなど)は、その後も成立(完了)する可能性があります。つまり、ブラックホール化後も追加のトークンが発行されたり、XRPがアカウントから流出したりする可能性があります。
