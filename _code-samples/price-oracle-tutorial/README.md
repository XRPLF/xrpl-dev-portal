# Create, Query, and Delete a Price Oracle

Create a [Price Oracle](/docs/concepts/decentralized-storage/price-oracles.md) on the XRP Ledger, query the price data it holds, and delete it. A Price Oracle is a mechanism that feeds external data, such as asset prices and exchange rates, onto the XRP Ledger.

See the tutorial, [Create, Update, and Delete a Price Oracle](/docs/tutorials/defi/price-oracles/manage-a-price-oracle.md), for a full walkthrough of this sample code.
